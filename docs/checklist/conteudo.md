## Imagens e alternativas textuais

> A alternativa textual deve transmitir a função ou informação da imagem, não apenas descrever sua aparência. O objetivo é preservar o significado para quem não vê a imagem.

- [ ] **Texto em imagem**: imagens com texto devem conter alternativa textual com o mesmo conteúdo.
- [ ] **Preferência por texto real**: sempre que possível, usar texto HTML em vez de imagem contendo texto.
- [ ] **Uso restrito de imagem de texto**: usar imagens de texto apenas para fins decorativos ou quando forem essenciais, como logotipos (WCAG nível AAA).
- [ ] **Personalização visual**: usar imagem de texto somente quando a apresentação visual for essencial ou puder ser personalizada pela pessoa usuária.
- [ ] **Descrição significativa**: fornecer alternativa textual para todo conteúdo visual, combinando tipo, quem ou o quê, ação e contexto.
- [ ] **Imagem decorativa**: usar atributo `alt=""` em imagens decorativas para que tecnologias assistivas as ignorem.
- [ ] **Imagem complexa**: oferecer descrição detalhada para gráficos, diagramas, mapas ou imagens que contenham informação densa.

## Formulários

> Formulários são pontos críticos de interação. Eles devem informar o que é esperado, prevenir erros e permitir recuperação sem perda de dados.

- [ ] **Formulários objetivos**: manter formulários curtos e com rótulos HTML apropriados.
- [ ] **Campos obrigatórios**: identificar claramente quais campos são obrigatórios antes do envio.
- [ ] **Rótulos programáticos**: associar rótulos aos campos de forma programática, permitindo leitura correta por tecnologias assistivas.
- [ ] **Descrição de erro**: informar em texto qual é o erro e qual campo foi afetado, preferencialmente próximo ao campo.
- [ ] **Evitar repetição de dados**: não solicitar novamente informações que a pessoa já forneceu, exceto quando necessário por segurança.
- [ ] **Reautenticação sem perda**: preservar dados já preenchidos sempre que possível em caso de reautenticação.
- [ ] **Dados sensíveis**: identificar claramente campos que coletam dados pessoais ou sensíveis.
- [ ] **Finalidade do campo**: indicar corretamente a finalidade de entradas como nome, e-mail, telefone, senha ou endereço.
- [ ] **Tempo limite em formulário**: avisar antes da expiração quando houver limite de tempo.
- [ ] **Correção segura**: orientar a correção de erros sem expor informações sensíveis.
